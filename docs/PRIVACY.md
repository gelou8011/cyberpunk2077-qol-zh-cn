# 公开上传前的隐私检查

本仓库由明确的文件清单重新整理，没有直接上传本地工作目录。检查对象为最终 Git 暂存区中的全部待上传内容，包含文本、UTF-16 字符串和 CET 二进制。

已排除：

- 游戏存档、用户资料、个人快捷键和完整 CET 配置。
- 安装前备份、游戏运行日志、构建日志、临时检测脚本及结果中的本机备份位置。
- 工具下载、缓存、Python 字节码、Git 凭证、令牌和私钥。
- 含会话、分享来源和追踪参数的链接。

检查发现并清除了公开 CET 副本中的 1 处 PDB 目录和 6 处断言源码目录；仅保留文件名。逐字节验证显示，二进制变化均位于这 7 个诊断字符串范围内，程序代码、导入表和布局保持原样。本机已经安装的游戏文件没有因上传准备而改变。

最终扫描检查了本机用户名、用户目录、工作区及游戏安装路径的 UTF-8、转义和 UTF-16 表达，以及常见凭证、私钥模式和不应上传的文件类型。未发现这些个人资料残留。原作者许可证中的公开联系信息保留，以满足署名与许可要求。

Git 提交使用 GitHub 公开用户名与 GitHub 提供的 noreply 地址。仓库只保留公开账号名，不使用个人邮箱。本报告针对本次发布文件；后续加入新文件时应重新检查。
